It started with a friend. In 2019 they got selected for Google Summer of Code, and I wanted to see what open source was about for myself.

My first merged pull request was a docs fix for [webpack](https://github.com/webpack/webpack.js.org/pull/2820), in February 2019. I was in my third year of college in Delhi. One page of their guide was out of date, so I changed it, and someone merged it.

After that I kept sending small things. CSS fixes for OSSN's [fixme](https://github.com/ossn/fixme), a link in the React Native docs, a margin bug in Gatsby. The first one that touched real library code was in [p5.js](https://github.com/processing/p5.js/pull/4043): `round()` got an optional second argument, so you could round to a number of decimal places. A few months later I deleted an old method from p5 too, which felt just as good.

In early 2020 I spent a lot of time in the [Vega editor](https://github.com/vega/editor): a focus bug, search in the signal view, and later gist limits on its backend.
